## Usage

### For System Backup:
1. Launch Macrium Reflect and navigate to the **Backup** tab.
2. Load the provided system backup profile (`.xml` configuration file).
3. Review and adjust the backup source and destination path.
4. Select the backup schedule (daily, weekly, or monthly) if needed.
5. Click **Backup now** to execute the plan.

### For Disk Cloning:
1. Open Macrium Reflect and go to the **Clone Disk** option.
2. Load the disk cloning template from the collection.
3. Select the source disk and destination drive.
4. Configure clone options (sector-by-sector, intelligent copy, etc.).
5. Start the cloning process and wait for completion.

### For File & Folder Backup:
1. Open Macrium Reflect and go to the **Backup** tab.
2. Select **Files and folders** as the backup source.
3. Load the appropriate file backup profile.
4. Choose your destination (local, external, or network).
5. Execute the backup or schedule it for automatic execution.

### For Incremental & Differential Backups:
1. Load the incremental or differential backup profile.
2. Set the full backup schedule and the incremental/differential interval.
3. Configure retention policies to manage backup storage.
4. Execute the backup plan to create the initial full backup.
5. Subsequent backups will automatically follow the configured schedule.

### For Disaster Recovery:
1. Use the rescue media profile to create a bootable USB or CD/DVD.
2. Follow the disaster recovery guide in the documentation.
3. In case of system failure, boot from the rescue media.
4. Select **Restore** and browse to locate your backup image.
5. Follow the wizard to restore your system, disk, or files.

### For Scheduled Automation:
1. Open the script folder and select the appropriate script (`.bat`, `.ps1`, or `.cmd`).
2. Edit the script to set your backup source, destination, and schedule.
3. Run the script manually or add it to Windows Task Scheduler.
4. Monitor execution through log files generated by the scripts.
5. Customize the scripts to fit your specific backup requirements.
